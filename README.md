# Lunar Eclipse Align Tool

月食照片批量平移对齐工具。它以月球外缘的几何中心为基准，适用于从偏食、全食到复圆阶段亮度跨度很大的序列。

当前版本：**V1.5.0-beta**

构建文件名：`Lunar_Eclipse_Align_Tool_V150b`

## V1.5.0-beta 更新

- 修复外部参考图与输入图片同名时误保存参考图的问题，使用规范化完整路径区分文件。
- 初定位失败时也会尝试参考半径环积分；仅当独立回退定位通过验证后才保存。
- 初定位候选选择不再受 6 秒耗时阈值影响，避免机器速度和系统负载改变检测分支。
- 中性 RGB 图片缺少有效红蓝色差时使用更严格的亮度验证；有效双通道定位冲突时仍拒绝候选。
- TIFF/JPEG 编码移至单后台写入线程，与下一帧的 OpenCV 检测并行；队列最多保留两张输出图，兼顾速度和内存占用。
- 同一帧的圆、椭圆和参考半径拟合复用一次归一化灰度图，减少重复的全图百分位统计与高斯降噪。
- 不再每帧强制执行 Python 全量垃圾回收；改为定期检查内存，超过阈值时才回收。
- 这些优化使用线程而非多进程，兼容 Windows/macOS 的 Tkinter GUI 和 PyInstaller 单文件构建。

## V1.4.0-beta 更新

- 每张目标图都独立定位，不再使用上一帧的圆心、半径或椭圆形状作为先验，因此处理顺序不会改变定位结果。
- 月缘覆盖充分时，使用带严格约束的单帧椭圆拟合，可容纳低高度角大气差分折射造成的轻微纵向压缩。
- 所有椭圆候选都会尝试用同一帧的参考半径环积分交叉校验圆心；环积分通过验证且两者圆心分歧超过 3 像素时拒绝椭圆，避免半径看似正常却仍存在圆心偏差。环积分无有效解时保留已通过外缘检查的椭圆。
- 偏食阶段只剩短月缘时，使用参考图的月面半径作为尺度约束，只求当前帧圆心，减少圆心与半径相互补偿导致的跳动。
- 常规月缘采样失败时，自动在检测副本上执行背景校正、先降噪和双通道固定半径环积分，恢复极低对比度月面；保存的原图不会被增亮或降噪。
- RANSAC 使用帧内固定随机数生成器，相同输入和参数可重复得到相同结果。
- 所有常规对齐仍然只做平移，不缩放、不旋转，也不会拉伸月面。
- 实验性月面纹理微调保持默认关闭；上述外缘改进不需要勾选该选项。

## 主要功能

- 批量读取 TIFF、BMP、PNG、JPEG 月食照片。
- 通过霍夫圆检测完成初定位，再利用物理月缘进行亚像素级圆心精定位。
- 支持选择参考图；未指定时会从输入序列前若干张中自动选择。
- 提供预览与半径估计窗口，可在正式处理前检查检测结果。
- 提供强力降噪检测模式；它只影响定位，不修改输出图像内容。
- 尽可能保留源图 EXIF 与 ICC 色彩配置。TIFF 元数据保留依赖 `tifffile`。
- 增量处理并逐张保存，避免整批照片同时占用内存。

## 对齐原理

常规流程分为三个步骤：

1. **初定位**：霍夫圆和稳健圆拟合估算月面位置与半径。
2. **外缘精定位**：沿径向采样由月面指向天空的亮度下降边缘，并用鲁棒方法排除星点、云层和噪声干扰。
3. **低信噪比回退**：常规采样失败时，在临时分析副本上扣除平滑天空背景、先降噪，再分别从亮度和红蓝色差通道积分参考半径处的圆环响应；两个通道定位一致且峰值显著时才接受。
4. **仅平移输出**：将目标图的几何中心移动到参考图中心，保持原始像素尺度和方向。

当单帧可见月缘足够多时，程序会尝试受约束椭圆。椭圆只有在覆盖范围、轴比、尺寸、中心偏差和拟合残差都通过检查时才会采用；否则回退到稳健圆。短月牙无法同时可靠确定圆心和半径，因此使用参考图半径补足尺度约束，但仍不会读取任何其他目标帧的信息。

> 椭圆几何模型在这里用于容纳可能由大气差分折射等因素造成的轻微非圆形外观。程序不会对照片做反变形，也不会把椭圆重新拉成正圆。

## 安装与运行

需要 Python 3.10 或更高版本。建议使用虚拟环境：

```bash
python -m venv .venv
```

Windows：

```powershell
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

macOS / Linux：

```bash
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

## 使用方法

1. 选择包含待对齐照片的输入文件夹。程序会自动建议名为 `_aligned_V150b` 的输出文件夹。
2. 打开“预览 & 半径估计”，选择一张月缘清晰、信噪比较高的照片。
3. 自动检测或框选月面，并将检测半径和当前照片应用为参考。
4. 检查最小/最大半径范围。范围应覆盖真实月面半径，但不宜过宽。
5. 保持“实验性月面纹理微调”关闭，先使用常规流程处理。
6. 查看日志中的定位模型、月缘覆盖率和拟合残差；必要时再调整检测参数。

## 参数说明

- **最小半径 / 最大半径**：月面半径的搜索范围，单位为像素。准确的范围能显著降低误检概率。
- **参数 1（Canny）**：边缘检测阈值。噪声多时可适当提高，暗弱月面可适当降低。
- **参数 2（累加阈值）**：霍夫圆候选的严格程度。数值越高越保守；漏检时可降低，误检时可提高。
- **强力降噪**：用于云层、噪声或极暗照片的检测预处理，不会对保存的照片做降噪。
- **实验性月面纹理微调**：在外缘对齐后利用月面纹理估算残余平移，默认关闭。偏食期间纹理与明暗结构变化很大，不建议作为首选方案。

## 使用建议与限制

- 参考图应当月缘清楚、不过曝，且月面尺寸与整组照片接近。
- 完全看不到月缘、严重失焦、厚云遮挡或大面积过曝的图片没有足够几何信息，无法保证可靠对齐。
- 如果镜头焦距、裁切比例或相机方向在拍摄过程中发生变化，仅平移模型无法修正这些差异。
- 对齐会在画面边缘产生黑色空白区域，这是保持原画幅尺寸进行平移的正常结果。
- `beta` 版本建议保留原始照片，并先用少量样张验证参数。
