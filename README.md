# Lunar Eclipse Align Tool

月食照片批量平移对齐工具。它以月球外缘的几何中心为基准，适用于从偏食、全食到复圆阶段亮度跨度很大的序列。

当前版本：**V1.5.1-beta**

构建文件名：`Lunar_Eclipse_Align_Tool_V151b`

## 当前源码更新：逐帧独立的浮动半径拟合

以下改动已在源码中启用；已有 `dist` 安装包没有自动更新。版本号暂未变更。

- 每张图自行在全图缩略图上初定位，再在本张图的原始分辨率局部区域精修。参考图只提供输出对齐位置，不给目标图提供固定半径、圆心先验或椭圆形状。
- 使用包含正圆的统一椭圆模型，不再按残差阈值在圆与椭圆之间切换。半径、形状和中心逐帧独立优化，不再使用固定参考半径回退。
- 月缘采样改用每条径向剖面的局部噪声阈值，结合本帧内的轻度角向平滑，避免仅保留亮侧最强边缘。分析保留浮点精度，原图不增亮、不降噪。
- 暗帧使用多半径环积分产生初定位候选，候选还必须通过自由几何精修。环积分不是最终定位，也不默认优于椭圆解。
- 增加有效月缘覆盖、搜索边界、分弧全参数重拟合和多初值分歧检查。不可靠帧跳过，批处理继续；结束后弹窗提示，并保存完整 `alignment-review.txt` 和 `alignment-report.json`。
- 修复初定位越过用户半径范围后仍返回原候选的问题。参考图自身不可靠时要求更换，不再直接采用霍夫粗定位作为基准。
- GUI 新增“分析并行”：自动按 CPU 和可用内存选择 1–2 路，也可选择 1、2、4 路（受资源预算限制）。另有单后台写入线程；在途任务有界，不一次性加载整个目录。不会改动进程全局 OpenCV 线程设置。
- 环积分复用通道 FFT，缓存有容量限制的只读卷积核频谱及背景坐标模板。缓存不包含任何图像的圆心、半径、像素或拟合结果。
- 现有同名对齐输出不覆盖；重新测试请使用新输出目录。当前不提供续跑。`alignment-report.json` 的检测器标识为 `independent-continuous-shape-v2`。

独立性回归测试：

```bash
python -m unittest discover -s tests -v
python tools/validate_independence.py sample_da --radius 370 430
```

第二条命令只读取素材，比较同一张图在单路、逆序两路、乱序四路和单张运行中的定位与质量判定，不写对齐图片。

注意：更严格的质量判定可能跳过旧版曾输出的图片，不能把“没有输出”解读为该原图一定无法定位。它表示当前算法无法充分验证这张图的几何中心；检查报告中的具体原因，或选择更合适的半径范围。已保存的低残差结果也不等同于有人工真值保证的绝对精度。

### 主流程：圆与椭圆的连续过渡

精修统一采用五参数对称形状矩阵。正圆对应两个各向异性分量为零，不直接优化在近圆情况下难以确定的长轴角度。内部使用矩阵的谱 logistic 映射，保证两条半轴都在用户半径范围内；没有固定水平长轴、固定半径或相邻帧形状约束。圆拟合只用于本帧月缘采样的初始定位，不再作为最终模型的另一条输出分支。

增加弱的、无方向偏好的形状正则项（系数 `0.002`，记录在报告中）。它只抑制缺乏证据的扁率，不把真实椭圆强制拉圆。为防止正则化制造“虚假的稳定”，每张图都会比较无正则化及四倍正则化下的中心；偏移超过 1 像素或任一检查不收敛时列入复查。分弧检验同样使用**无形状正则化**的全参数重拟合，继续拒绝短弧歧义、超限轴比、低覆盖和不稳定中心。

报告的 `geometry.model` 为 `unified-ellipse`；`shape_vector` 是 `((a-b)/(a+b) cos(2θ), (a-b)/(a+b) sin(2θ))`，`shape_sensitivity` 是改变正则化强度后的最大中心偏移（像素）。`axes` 按长、短半轴排序，`angle` 只是导出的长轴方向，用于画图，不参与跨帧反馈。接近正圆时角度本身仍可能变化很大，应查看趋近零的 `shape_vector`，不要把一个不确定的长轴角度当成位置跳动。

这是**模型的连续性**，不是时间轴平滑。输入顺序不影响定位，也不会消除真实的大气或镜头形变；输出仍仅平移原图，绝不通过拉伸月面制造平滑外观。

物理边界参考：[Corbard 等（2019），DOI:10.1093/mnras/sty3391](https://doi.org/10.1093/mnras/sty3391)。该文讨论纯大气折射的竖直压缩及其在图像中的方向；本软件没有所需的完整观测几何和气象信息，因此不把图像 X/Y 轴当成固定的大气折射方向。连续参数化与正则化门槛是本项目的实现选择，并非该论文给出的月食定位精度保证。

## 实验性纹理微调：统一算法与使用边界

界面现在只有一个“启用实验性月面纹理微调”开关，默认关闭。旧的 `auto / phase_corr / template / feature / centroid` 下拉框已移除；之前这些名称没有对应五条独立的实现。旧调用接口的 `alignment_method` 参数暂时保留兼容，所有名称都明确映射到同一算法，并记录日志。

统一算法 `texture-consensus-v2` 在本张图已经完成独立月缘定位后运行：

- 修正位移方向：测得目标相对参考的偏移后，输出反向纠正矩阵，避免越对越偏。最终仍从原图一次插值输出，不对彩色结果重复变换。
- 在分析副本中使用有正负值的浮点双尺度带通，去掉 CLAHE、uint8 高通截断和拉普拉斯绝对值强化；不增亮或降噪保存的原图。
- 仅在月盘内部挑选空间分散的纹理块，同时检查目标块的有效像素和纹理信噪比。使用真正减去均值的 ZNCC，拒绝模糊峰、搜索边界和重复图案。
- 模板匹配后才尝试相位亚像素残差；相位输入减均值并加 Hann 窗。相位响应与 ZNCC 分开判断，只有不降低匹配质量且符合第二尺度时才采用。
- 检查正反向匹配、两个尺度的位移一致性、多块位移共识与空间覆盖。至少需要 6 个可靠块、共识占比不低于 75%、覆盖至少 3 个象限；最多纠正 6 像素。这些是经验质量门槛，不是精度保证。
- 固定有限的纹理块数量，不再因机器运行速度或 1.2 秒超时而改变所用证据。不会读取上一帧位置，不做时间平滑，也不缩放、旋转或局部拉伸图像。
- 不可靠的纹理结果只会**放弃微调并保留原来的月缘位移**，不会因此丢掉一张已通过月缘检查的图。日志和 `alignment-report.json` 的 `texture_refinement` 字段记录采用状态、原因、纠正量和质量信息。

### 曝光、视宁与天平动不是同一个问题

全局曝光倍率和亮度偏置可在一定条件下通过相关归一化缓解，但过曝、暗部信号丢失及局部阴影变化会减少共同可见纹理。当前算法不尝试“补出”消失的地形；共同纹理过少或集中在一侧时应拒绝微调。

双尺度带通和多区域检查旨在降低模糊、噪声及局部视宁形变对平移估计的干扰，**不是大气湍流复原算法**。纹理对齐也不等于几何圆心对齐：天平动、投影变化及局部形变可能使不同地形不再对应同一个平移；即使通过一致性检查，也不能证明没有这类偏差。整场月食、大曝光跨度的批处理仍建议关闭实验开关；只有共同纹理充分的素材才值得小批量比较。

方法参考：[Löfdahl (2010), Evaluation of image-shift measurement algorithms for solar Shack–Hartmann wavefront sensors, arXiv:1009.3401](https://arxiv.org/html/1009.3401)。原文区分已知平移、噪声、强度差及模拟视宁条件，并指出几何畸变的影响还需要另外评估。这里借鉴的是测试和误差分类方法，并不将太阳波前传感实验的精度直接套用到月食照片。

测试覆盖：已知整数/亚像素平移、曝光倍率与偏置、适度模糊与噪声、缓变照明、单侧纹理、非刚性形变、低信噪比拒绝、16 位保真、粗定位位移组合和乱序并行确定性。运行 `python -m unittest discover -s tests -v`。

- RANSAC 使用帧内固定随机数生成器，相同输入和参数可重复得到相同结果。
- 所有常规对齐仍然只做平移，不缩放、不旋转，也不会拉伸月面。
- 实验性月面纹理微调保持默认关闭；上述外缘改进不需要勾选该选项。

## 主要功能

- 批量读取 TIFF、BMP、PNG、JPEG 月食照片。
- 通过霍夫圆检测完成初定位，再利用物理月缘进行亚像素级圆心精定位。
- 支持选择参考图；未指定时会从整个文件列表均匀抽取最多 12 张候选，选择通过质量检查的参考。
- 提供预览与半径估计窗口，可在正式处理前检查检测结果。
- 提供强力降噪检测模式；它只影响定位，不修改输出图像内容。
- 尽可能保留源图 EXIF 与 ICC 色彩配置。TIFF 元数据保留依赖 `tifffile`。
- 增量处理并逐张保存，避免整批照片同时占用内存。

## 对齐原理

当前常规流程分为四个步骤：

1. **初定位**：在每张图自身的缩略图上，用霍夫圆和稳健圆拟合估算月面位置与半径。
2. **外缘精定位**：在本帧原始分辨率局部区域沿径向采样亮度下降边缘，使用有边界的统一圆/椭圆模型鲁棒拟合。半径、形状都可浮动，接近圆时无需确定长轴角度。
3. **低信噪比候选与质量检查**：难帧在临时分析副本上扣除平滑背景，搜索允许半径范围内的圆环响应，再回到原始分辨率做几何拟合。检查本帧有效覆盖、分弧重拟合稳定性和候选分歧；不足以确定中心时列入复查，而非强制套用参考图的圆。
4. **仅平移输出**：将目标图的几何中心移动到参考图中心，保持原始像素尺度和方向。

最终始终使用统一椭圆模型，正圆是其特例。当前要求半轴在用户范围内、短长轴比不低于 0.94；分弧验证会同时重拟合中心和全部形状参数，不锁定形状来制造稳定性。短月牙可能无法同时可靠确定圆心、半径与形状，这类图片会跳过并报告，不借用其他帧的信息补足。

> 椭圆几何模型在这里用于容纳可能由大气差分折射等因素造成的轻微非圆形外观。程序不会对照片做反变形，也不会把椭圆重新拉成正圆。

```bash
python -m venv .venv
```

```powershell

pip install -r requirements.txt
python main.py

source .venv/bin/activate

python main.py
```

## 使用方法

1. 选择包含待对齐照片的输入文件夹。程序会自动建议名为 `_aligned_V151b` 的输出文件夹。
2. 打开“预览 & 半径估计”，选择一张月缘清晰、信噪比较高的照片。
3. 自动检测或框选月面，并将检测半径和当前照片应用为参考。
4. 检查最小/最大半径范围。范围应覆盖真实月面半径，但不宜过宽。
5. 保持“实验性月面纹理微调”关闭，先使用常规流程处理。
6. 查看 `alignment-report.json` 中的中心、半轴、覆盖率、分弧稳定性及各阶段耗时；按 `alignment-review.txt` 复查跳过的图片。

## 参数说明

- **最小半径 / 最大半径**：月面半径的搜索范围，单位为像素。准确的范围能显著降低误检概率。
- **参数 1（Canny）**：边缘检测阈值。噪声多时可适当提高，暗弱月面可适当降低。
- **参数 2（累加阈值）**：霍夫圆候选的严格程度。数值越高越保守；漏检时可降低，误检时可提高。
- **强力降噪**：用于云层、噪声或极暗照片的检测预处理，不会对保存的照片做降噪。
- **实验性月面纹理微调**：在外缘对齐后利用月面纹理估算残余平移，默认关闭。偏食期间纹理与明暗结构变化很大，不建议作为首选方案。

## 使用建议与限制

- 参考图应当月缘清楚、不过曝，且月面尺寸与整组照片接近。
- 完全看不到月缘、严重失焦、厚云遮挡或大面积过曝的图片没有足够几何信息，无法保证可靠对齐。
- 如果镜头焦距、裁切比例或相机方向在拍摄过程中发生变化，仅平移模型无法修正这些差异。
- 对齐会在画面边缘产生黑色空白区域，这是保持原画幅尺寸进行平移的正常结果。
- `beta` 版本建议保留原始照片，并先用少量样张验证参数。
